# BattleFight 見た目の差し替えガイド

> ステータス: v1.0 / 最終更新: 2026-10-23

プレイヤー・敵・武器の見た目(モデル・マテリアル・アニメーション)を差し替えるための約束ごと。
プレハブの中身は自由に作り替えてよい。この文書に書いた **登録(参照)だけは保つ** こと。

## 1. どこに何があるか

| 種類 | プレハブ | つないでいる所 |
|---|---|---|
| プレイヤー | `Assets/_Project/Prefabs/Player/Player.prefab` | シーンに置いてある |
| 敵の土台 | `Assets/_Project/Prefabs/Enemies/Enemy_Base.prefab` | 種類ごとのプレハブの元(バリアントの親) |
| 敵(種類ごと) | `Assets/_Project/Prefabs/Enemies/Enemy_*.prefab`(Enemy_Base のバリアント) | `Data/Enemies/Enemy_*.asset` の **Prefab** |
| 武器(武器種ごと) | `Assets/_Project/Prefabs/Weapons/Weapon_*.prefab` | `Data/Weapons/Weapon_*.asset` の **Prefab** |

- 最初の中身は、コードで作った仮モデル(箱・カプセル)。
- シーンを作り直す(`BattleFight/Build Prototype Arena`)とき、**プレハブがあれば中身には手を付けない**。差し替えた見た目は消えない。
- 仮モデルから作り直したいときは、そのプレハブを消してからシーンを作り直す。
- 体力・攻撃・速さなどの中身は、プレハブではなく `Data/` のデータで決める。見た目を替えても強さは変わらない。

## 2. キャラクター(プレイヤー・敵)

キャラクターの見た目は、プレハブの中の **Visual** にまとまっている。Visual には `CharacterVisual` が付いている。

```
Player(または Enemy_*)        ← 当たり(CharacterController)と、動かすためのコンポーネント。触らない
└─ Visual                      ← CharacterVisual。この下を差し替える
    ├─ Body                    ← 体(仮モデルではカプセル)
    ├─ HandAnchor              ← 手(プレイヤー。武器がここに付く)
    └─ HeadAnchor              ← 頭の上(エリートの冠が付く)
```

### CharacterVisual に登録するもの

| 項目 | 何に使うか | なくてもよいか |
|---|---|---|
| Body | のけぞり・つぶれ・ひねりで動かす。回避の残像は、これの下のメッシュを写す | 空なら Visual そのものを使う |
| Hand Anchor | 武器のプレハブを、この下に置く(+Z が武器の先の向き)。手のボーンの子に置くとよい | プレイヤーは必須 |
| Head Anchor | エリートの冠を付ける | 空なら Visual の上 2.25m |
| Weapon Renderer | 敵が手に持つ武器。型を切り替えると、型の色で塗る | 型を持たない敵は不要 |
| Animator | アニメーションを流す(3 章) | なくてもよい |
| Procedural Motion | コードで動かす仮の動き(のけぞり・つぶれ・ひねり・武器の振り)を使うか | Animator で動かすなら外す |

### 守ること

- 足元をプレハブの原点(0, 0, 0)に、正面を +Z に合わせる。体の高さはおよそ 2m(当たりの大きさが 2m のため)。
- ボーンで動くモデル(SkinnedMeshRenderer)でもよい。残像はその瞬間の形を写す。
- 敵の色(攻撃を受けたときの白い光・予備動作の色)は、マテリアルの **Base Color** に掛けて出す。テクスチャを使うときは Base Color を白にしておく。
- マテリアルは必ずアセットにする(プレハブの中で作ったマテリアルは保存されない)。

## 3. アニメーション

キャラクターのルートの `CharacterAnimation` が、合図を Visual の Animator に流す。
**Animator に同じ名前のパラメーターがあれば送り、なければ何もしない**。使うものだけ作ればよい。

| パラメーター | 型 | いつ |
|---|---|---|
| `Speed` | float | いつも(水平の移動の速さ、m/秒) |
| `Grounded` | bool | いつも(地面に立っているか) |
| `Guard` | bool | ガードを構えている間 |
| `Weapon` | int | 技の武器種(0 剣・1 大槌・2 鎖・3 杖・4 銃・5 籠手) |
| `Step` | int | コンボの段(0 から) |
| `Slot` | int | 技のスロット(0 攻撃A・1 攻撃B・2 移動) |
| `Attack` | trigger | 技の段が始まった(敵は予備動作が始まった) |
| `Dodge` | trigger | 移動スキル(回避)が始まった |
| `Jump` / `Land` | trigger | 踏み切った / 着地した |
| `Hit` | trigger | 攻撃を受けてひるんだ |
| `Parry` | trigger | パリィを決めた |
| `Die` | trigger | 倒れた |

### 技ごとに決まったアニメーションを流す

技のデータ(`Data/Skills/Skill_*.asset`)と、敵の攻撃(`Data/Enemies/Enemy_*.asset` の Attacks)には **Animation State** がある。
ここに Animator のステートの名前を書くと、合図の代わりにそのステートへ切り替える(ベースレイヤー、0.05 秒でつなぐ)。
ステートがなければ、ふつうの合図(`Attack` など)を出す。

### コードの仮の動きとの関係

- Animator だけで動かすなら、CharacterVisual の **Procedural Motion** を外す。コードは体・手を動かさなくなる。
- 付けたままでも動くが、コードの動き(体の傾き・手の回転)が Animator の上に重なる。

## 4. 武器

```
Weapon_Sword                   ← WeaponVisual。原点が手の位置、+Z が武器の先の向き
├─ (モデル)
└─ Tip                         ← 武器の先。振ったときの軌跡はここから出る
```

| 項目 | 何に使うか | なくてもよいか |
|---|---|---|
| Tip | 振ったときの軌跡を出す位置 | 空なら原点 |
| Trail | 振ったときの軌跡(TrailRenderer)。攻撃判定が出ている間だけ描く | 空なら先に自動で付ける |

- 武器の振りは、コードが手(HandAnchor)を回して出している。Animator で振るなら、キャラクターの Procedural Motion を外す。
- 持ち替えた瞬間に、武器のルートの大きさを一瞬大きくする。ルートの大きさは 1 のままにする(モデルの大きさは子で調整する)。

## 5. 演出(エフェクト)

演出は「場面」ごとに差し替える。差し替え表は `Assets/_Project/Data/EffectLibrary.asset`。
場面の行にプレハブ(パーティクルなど)を入れると、**いつもの演出(コードで作る仮の演出)の代わりに** それを出す。
空の行は、いつもの演出のまま。

| 項目 | 何に使うか |
|---|---|
| Prefab | 出す演出。空ならいつもの演出 |
| Scale With Size | 場面の大きさ(衝撃波の半径・着地の強さ・技の範囲など)に合わせて拡大するか。外すと Scale のまま |
| Scale | 大きさの倍率 |
| Use Color | 場面の色(武器の色・敵の予告の色など)を、パーティクルの開始色に入れるか |
| Lifetime | 出しておく秒数。0 ならパーティクルの長さから決める(パーティクルがなければ 2 秒) |

### 場面の一覧

| 場面 | いつ | 大きさ | 向き |
|---|---|---|---|
| HitSpark | 攻撃が当たった | 1(重い一撃・締めは 1.4) | — |
| HitImpact | 武器ごとの当たりの形 | 1(重い一撃・締めは 1.4) | 攻撃の向き |
| ArmorBreak | 敵のアーマーが砕けた | 1 | — |
| Defeat | 敵を倒した(刻片が飛んでくるのは差し替えても残る) | 敵の大きさ | 敵の向き |
| SwingArc | 振ったときの斬撃の弧 | 弧の半径 | 振る面(+Z が正面) |
| AreaAttack | 広い範囲の技の地面の輪 | 範囲の半径 | プレイヤーの向き |
| Beam | ビーム | ビームの太さ | 撃った向き |
| ProjectileBurst | プレイヤーの弾の爆発 | 爆発の半径 | — |
| Counter | 居合のカウンター | 1 | — |
| DodgeStart | 移動スキル(回避)の出だし | 1.1 | プレイヤーの向き |
| BlinkOut / BlinkIn | ブリンクで消えた / 現れた | 1.2 / 1.6 | プレイヤーの向き |
| Jump / Land | 踏み切り / 着地 | 0.9 / 0.8〜2.6(落ちた速さ) | — |
| WeaponSwap | 武器の持ち替え | 1.4 | プレイヤーの向き |
| ChangeAttack / ChangeDrive | チェンジアタック / チェンジドライブ | 技の範囲の半径 | プレイヤーの向き |
| Guard / Parry | ガード / パリィ | 1 | プレイヤーの向き |
| JustDodge | ジャスト回避(見切り) | 3.5 | プレイヤーの向き |
| PlayerHurt | プレイヤーが攻撃を受けた | 1(重い一撃は 1.4) | — |
| AttackGlint | 敵の攻撃の直前のきらめき(パリィ・見切りの合図) | 1 | 敵の向き |
| EnemyAttackLand | 敵の近接攻撃が地面に当たった | 攻撃の半径 | 敵の向き |
| EnemyTeleport / EnemySummon | 敵の瞬間移動 / 仲間を呼んだ | 敵の大きさ + 1 / + 2 | 敵の向き |
| EnemyPhase2 | ボスが第二形態になった | 敵の大きさ + 4 | 敵の向き |
| EnemySkillSwap | 写し身が型を切り替えた | 敵の大きさ + 1.2 | 敵の向き |
| EnemyProjectileBurst | 敵の弾の爆発 | 爆発の半径 | — |
| SkillPickup / WallBreak | スキルを拾った / 壁を壊した | 2.5 / 壁の大きさ | — |

- 「—」の場面は向きを付けない(ワールドの向きのまま)。
- 演出は使い回す(出し終わったら隠してしまっておき、次に出すときに最初から流し直す)。プレハブの中で自分を消さないこと。
- 回避の残像は、キャラクターの見た目をその場で写すので差し替えない。

## 6. 確かめ方

- `PrefabContractTests`(EditMode): プレハブに CharacterVisual・WeaponVisual があるか、登録が抜けていないか、マテリアルがアセットか、敵・武器のデータがプレハブにつながっているか。
- `EffectLibraryTests`(EditMode): 差し替え表に、すべての場面の行が 1 つずつあるか。シーンにつながっているか。
- `PrefabSwapPlayTests`(PlayMode): プレハブの見た目で出るか、別の見た目に替えられるか、アニメーションの合図が出るか。
- `EffectSwapPlayTests`(PlayMode): 差し替えた演出が、いつもの演出の代わりに出るか。色が入るか。消えるか。

差し替えたあとは、これらのテストを回して通ることを確かめる。

## 7. まだ差し替えられないもの

- 敵の攻撃範囲の表示・ガードの盾・弾の見た目。
- シーン(アリーナの地形・UI)。シーンはまだコードから毎回作り直している(次に直す予定)。
