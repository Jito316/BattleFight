# BattleFight ゲームデザイン仕様書(ドラフト)

> ステータス: ドラフト v0.4 / 最終更新: 2026-09-29

---

## 1. コンセプト

**「武器を持ち替え続けて、流れるように戦う3Dメトロイドヴァニア」**

- ジャンル: 3D アクション / メトロイドヴァニア / PvE
- 戦闘テンポ: DMC 系のスタイリッシュで高速な戦闘
- 参考: 仮面ライダーオーズ(スロット別の入れ替え・コンボ)、Ender Lilies(スキル編成)、Devil May Cry(スタイルランク・スタイル切り替え)
- 開発: Unity 6 / URP / Input System(現在は個人開発、将来的にチーム開発)

### デザインの柱(ピラー)

1. **入れ替えがテクニックになる** — スロットを切り替えること自体が、コンボを伸ばし火力を上げる手段になる
2. **止まらない** — 戦闘中の入れ替えは1ボタン。メニューを開いての一時停止はしない
3. **スキルは戦闘の技であり、探索の鍵でもある** — 手に入れたスキルで行ける場所が広がる

## 2. スロットシステム

### 2.1 スロット構成

| スロット | 役割 | 武器の扱い |
|---|---|---|
| **攻撃A(メイン武器)** | 連撃・主力ダメージ | 手に持つ武器。見た目もこれで変わる |
| **攻撃B(特殊技)** | 特殊技・範囲・中距離・溜め | その武器種の **メイン武器の特殊技**。発動中だけその武器に持ち替える |
| **移動** | 回避・位置取り・空中機動 | 武器を使った移動アクション。発動中だけその武器に持ち替える |

すべてのスキルは **武器種(系統)** に属する。

### 2.1.1 武器モデルの扱い
- 武器モデルは **武器種ごとに1つ** とし、攻撃A・攻撃B・移動のすべてで共用する(召喚専用のサブ武器モデルは作らない)
- 普段手に持っているのは攻撃A の武器。攻撃B や移動の武器種が攻撃A と違う場合は、**発動中だけ瞬時に持ち替え**、終わったら攻撃A の武器に戻す
  - 例: 攻撃A = 剣、攻撃B = 地砕き(大槌)→ △を押すと一瞬で大槌に持ち替えて地面を叩き、終わると剣に戻る
- 持ち替えの演出はエフェクトで一瞬光らせる程度にとどめ、専用のモーションは作らない(工数の削減と、テンポを落とさないため)

### 2.1.2 リソース
- **スキルの使用に制限はない**(クールダウン・ゲージ・回数制限なし)
- 連発を抑える仕組みは次の3つで作る
  1. **フレームデータ**: 攻撃B は威力が高い分、開始や硬直を長くする
  2. **スタイルランクの減衰**: 同じ技の繰り返しはポイントが伸びない(4.2)
  3. **敵の行動**: 硬直を狙ってくる敵、特定の技を弾く敵を配置する

### 2.2 ラック(スロットごとの候補)

- 各スロットに **3つまで** スキルを登録できる(=ラック)
- 合計 3スロット × 3候補 = 最大9スキルを戦闘に持ち込める
- **ラックの編集はセーブポイント(祭壇)でのみ可能**
  - 未決事項: 戦闘外であればポーズメニューからの編集を許可するか(→ 11章)

### 2.3 戦闘中の切り替え(リアルタイム)

**方針: スキルの切り替えはすべてリアルタイムで行う。** メニューを開くことも、一時停止やスローも入れない。移動や攻撃をしながら、その場で1ボタンで切り替える。

| 入力(パッド / キーボード) | 動作 |
|---|---|
| 十字キー ← / 1 | 攻撃A のラックを次の候補へ切り替える |
| 十字キー → / 2 | 攻撃B のラックを次の候補へ切り替える |
| 十字キー ↓ / 3 | 移動 のラックを次の候補へ切り替える |
| 十字キー ↑ | (予約)回復アイテム、またはロックオン対象の切り替え |

- 切り替えは即時(0 フレーム)。技の実行中でも受け付ける
- 切り替えた武器の見た目は、その瞬間に持ち替わる(攻撃A の場合)

### 2.4 切り替え方式: ラック方式 / プリセット方式(試作中・比較用)

どちらが気持ちいいかを比べるため、2つの方式を編成画面で切り替えられるようにしている。

| 方式 | 戦闘中の操作 | 特徴 |
|---|---|---|
| ラック方式 | 1 / 2 / 3(十字 ← → ↓)で各スロットを順送り | 細かく組み替えられる。考えることが多い |
| **プリセット方式**(既定) | 1〜4(十字 ← → ↓ ↑)で3スロットを一括切り替え | 1ボタンで「型」ごと変わる。オーズのフォームチェンジに近い |

- プリセットは4つ。各プリセットに 攻撃A / 攻撃B / 移動 を1つずつ入れる
- プリセット方式でもスワップキャンセル・スワップストライクは有効
  - 実行中の技のスロットの中身が切り替え先で**変わるとき**だけキャンセルになる(同じ技なら続く)
  - HUD では、今切り替えるとキャンセルになるプリセットが点滅する
- 初期プリセット: 剣士(剣マスタリー)/ 魔導士(杖マスタリー)/ ガンナー(銃マスタリー)/ 混成(アーセナル)

### 2.5 編成画面(実装済み)
- **P / Select** で開閉。開いている間はゲームを止める
- 切り替え方式の選択、プリセットの名前、各スロットのスキルをマウスで選ぶ
- スキルにマウスを乗せると説明とフレーム数などの数値を表示し、プリセットの武器種ボーナスも表示する
- 閉じると保存する(WebGL ではブラウザに保存)。「初期のプリセットに戻す」あり

#### 切り替えのフィードバック(実装済み)
- 足元に、切り替えた武器種の色でリングが広がる
- HUD のスロットのパネルが外側へ光り、パネルの上に新しいスキル名(「⇒ 重撃」)が出る
- **今切り替えるとスワップキャンセルになるスロット**は、パネルの枠が水色で点滅し、「今なら切替でキャンセル」と表示する
- スワップストライクの受付中は「SWAP STRIKE READY」と、残り時間のバーを表示する
- HUD に各スロットの「現在の候補」と「次の候補」を常に表示し、押す前に何に変わるかがわかるようにする
- 未決事項: 逆順の切り替え(長押しで1つ戻るなど)を入れるか

## 3. 入れ替えを強くする仕組み

### 3.1 スワップキャンセル
- 技の **硬直中** にそのスロットを切り替えると、硬直をキャンセルできる
- キャンセルできるタイミングの窓は技ごとにデータで設定する(`SkillData.swapCancelFrame`)
- 乱用を防ぐため、同じスロットで連続してキャンセルした場合は、2回目以降の窓を狭くする(要調整)

### 3.2 スワップストライク
- 切り替えた直後の **最初の一撃** に強化効果がつく
  - 例: ダメージ ×1.3、スタイルポイントにボーナス、ひるみ値アップ
- 効果時間: 切り替えから 1.0 秒以内の最初のヒット(要調整)

### 3.3 武器種ボーナス(コンボ)

| 装備の状態 | 名称(仮) | 効果 |
|---|---|---|
| 3スロットすべて同じ武器種 | **マスタリー** | 専用フィニッシャーの解放、その武器種の性能強化 |
| 2スロットが同じ武器種 | **シナジー** | 小さな強化(例: その武器種の技のひるみ値 +10%) |
| 3スロットすべて違う武器種 | **アーセナル** | スタイルポイント獲得量アップ(多彩に戦うことへのご褒美) |

→ 「1つの武器種を極めて大技を撃つ」か「バラバラに持って高いランクを稼ぐ」かを選べるようにする。

### 3.4 弱点(実装済み)
- 敵ごとに弱点の武器種があり、その武器種の技で攻撃すると **ダメージ・ひるみが 1.5 倍**
- 敵の頭上に「弱 大槌 拳」のように表示。今の攻撃A の武器が弱点なら「**弱点**」と強調する
- 敵に合った武器(プリセット)に持ち替える理由を作る

| 敵 | 弱点 |
|---|---|
| 雑兵 | 剣・拳 |
| 重装兵 | 大槌・拳 |
| 射手 | 鎖・剣 |
| 疾風兵 | 杖・銃 |
| 飛蟲 | 銃・杖 |
| 爆弾兵 | 銃・鎖 |
| 鉄獣(ボス) | 大槌・鎖 |
| 魔導機(ボス) | 銃・拳 |

### 3.5 チェンジチェイン(実装済み)
- 切り替えてから **2.5 秒以内に攻撃を当てる** とチェインが 1 段上がる(1 回の切り替えにつき 1 段)
- 1 段ごとに **ダメージ +10%(最大 5 段 = +50%)**。段が上がるとスタイルにもボーナス
- 最後につないでから 4 秒たつか、被弾すると途切れる
- 「同じ技を振り続ける」より「切り替えながら戦う」ほうが強くなるようにする

### 3.6 チェンジアタック(実装済み)
- 切り替えた瞬間、新しい武器(攻撃A)で **周り(半径 2.6m)を一撃** する。クールダウン 3 秒
- 囲まれたときの押し返しや、切り替えそのものを攻撃にするため。これだけではチェインは上がらない

## 4. スタイルランク

### 4.1 表示
- **戦闘中は常に画面右側に表示する**(DMC 型)
- ランク: **D → C → B → A → S → SS → SSS**
- ランクごとに、アナウンス文字・色・効果音を変えて派手に演出する

### 4.2 ポイントの増減

| 要因 | 効果 |
|---|---|
| ヒット | ポイント加算(技ごとの基本値) |
| 同じ技の繰り返し | 加算量が減っていく(直近 N 回の履歴で判定) |
| 違う技・違う武器種でのヒット | 加算にボーナス |
| スワップストライク / スワップキャンセル | 加算にボーナス |
| ジャストの回避(被弾直前の回避) | 加算 |
| 被弾 | ランクが大きく下がる(1〜2段階) |
| 一定時間攻撃しない | ポイントが徐々に減る |

### 4.3 報酬
- 敵を倒したときの通貨(仮: 「刻片」)のドロップ量に、ランクに応じた倍率がかかる
- 部屋のクリア時に最高ランクを評価し、追加の報酬を出す(任意)

## 5. 武器種(MVP 分)

MVP では **3種類** に絞る。1種類につき 攻撃A / 攻撃B / 移動 のスキルを1つずつ用意し、合計9スキル。

### 5.1 剣(バランス型)
| スロット | スキル名(仮) | 内容 |
|---|---|---|
| 攻撃A | 連斬 | 速い4段コンボ。キャンセル窓が広く、つなぎに使いやすい |
| 攻撃B | 居合 | 溜めて放つ突進斬り。溜め中に被弾するとカウンターが発動する |
| 移動 | ステップ斬り | 短距離のダッシュ。無敵時間があり、通過した敵に攻撃判定がある |

### 5.2 大槌(重量型)
| スロット | スキル名(仮) | 内容 |
|---|---|---|
| 攻撃A | 重撃 | 遅い3段コンボ。**アーマーを破壊できる**。ひび割れた壁を壊せる |
| 攻撃B | 地砕き | 周囲に衝撃波を出す範囲攻撃。敵を打ち上げる |
| 移動 | ハンマージャンプ | 地面を叩いて高く跳ぶ。着地時に衝撃波が出る |

### 5.3 鎖(中距離・機動型)
| スロット | スキル名(仮) | 内容 |
|---|---|---|
| 攻撃A | 鎖鞭 | 中距離の連撃。範囲は広いがダメージは低め |
| 攻撃B | 引き寄せ | 小型の敵は手元に引き寄せ、大型の敵には自分が飛びつく |
| 移動 | ワイヤー | **視界内で一番近いグラップルポイント**へ直線で飛び、少しの間ぶら下がる(下記) |

#### ワイヤーの仕様(実装済み)
- 対象の優先順: ①視界内で一番近いグラップルポイント → ②ロックオン中の敵 → ③空中ダッシュ
  - 「視界内」= カメラに映っていて(画面端5%は除く)、プレイヤーからポイントまでの間に遮るものがないこと
  - 今ぶら下がっているポイント(2.5m以内)は対象から外すので、連続で使うと次のポイントへ渡っていける
- HUD では、今押したら飛ぶポイントに「◎」を表示する
- ポイントに着くと 0.6 秒ぶら下がる。その間に
  - ワイヤー → 次のポイントへ
  - ジャンプ → 入力方向へ跳ぶ
  - 攻撃 → 空中攻撃

### 5.4 追加した武器種とスキル(プリセット方式を試すため)

ジャンルを問わず候補を増やした(合計: 通常スキル34 + フィニッシャー6)。

| 武器種 | 攻撃A | 攻撃B | 移動 | フィニッシャー |
|---|---|---|---|---|
| 剣 | 連斬 / 疾風突き | 居合 / 飛燕斬(飛ぶ斬撃) | ステップ斬り / 残影(瞬間移動) | 千刃 |
| 大槌 | 重撃 / 旋風槌 | 地砕き / 隕鉄投げ(爆発) | ハンマージャンプ / 突撃 | 天崩 |
| 鎖 | 鎖鞭 / 鎖斬輪 | 引き寄せ / 縛鎖(追尾) | ワイヤー | 縛鎖陣 |
| **杖(魔法)** | 魔弾(追尾3連射) / 杖術 | 火球(爆発) / 落雷(遠隔の範囲) / 氷結陣 | ブリンク / 浮遊 | メテオ |
| **銃(SF)** | ラピッドショット / ショットガン | レーザー(貫通ビーム) / グレネード | ジェットブースト / スライド | オーバードライブ(全方位弾幕) |
| **拳** | 連打 | 昇龍拳(一緒に上昇) / ロケットパンチ | ロケットダッシュ | 百裂拳 |

新しく追加した技の挙動(`SkillBehavior`): 弾(Projectile)、ビーム(Beam)、遠隔の範囲攻撃(TargetedStrike)、瞬間移動(Blink)、ブースト(Boost)。

### 5.5 将来の候補
槍、双剣、拳(ガントレット)、銃、弓、鎌 など。
遠距離専用の武器種は、攻撃B に偏らせる前提で検討する。

## 5.6 ステージと敵(試作のボリューム)

### ステージ選択(起動時に表示)
| ステージ | 種類 | 内容 |
|---|---|---|
| 訓練場 | 練習 | 攻撃してこない人形(通常・重装・浮遊)が倒しても復活する。スキルやプリセットを試す場所 |
| 第1幕 鉄獣 | 4ウェーブ | 雑兵・重装兵 → ボス「鉄獣」 |
| 第2幕 空と銃火 | 5ウェーブ | 射手・疾風兵・飛蟲 → ボス「魔導機」 |
| 第3幕 爆炎の回廊 | 5ウェーブ | 爆弾兵の群れ → 鉄獣と魔導機の同時戦 |
| 第4幕 影の剣聖 | 4ウェーブ | 素早い敵の連戦 → ボス「影刃」 |
| エンドレス | 自動生成 | ウェーブが進むほど強い敵が混ざる。5ウェーブごとにボス |
| 探索 古城 | 探索 | マップを巡ってスキルを集める(6.3) |

- クリアすると「次のステージ [N] / もう一度 [R] / ステージ選択 [T]」
- ステージごとにベストタイムと最高ランク、エンドレスは最高ウェーブを保存する

### 敵
| 敵 | 特徴 | 対策の例 |
|---|---|---|
| 雑兵 | 基本の近接 | なんでも |
| 重装兵 | アーマー持ち。引き寄せられない | 大槌・重い技でアーマーを割る |
| 射手 | 距離を取りながら撃つ(単発/三連射) | 飛び道具、ワイヤー、ブリンクで詰める |
| 疾風兵 | 足が速く、長い突進斬り | 回避してから反撃 |
| 飛蟲 | 空を飛び、急降下と毒液 | 飛び道具、ワイヤー、昇龍拳 |
| 爆弾兵 | 近づいて自爆する | 近づかれる前に倒す、無敵のある移動で抜ける |
| 鉄獣(ボス) | 爪撃・突進・跳躍叩きつけ | アーマーを割ってから集中攻撃 |
| 魔導機(ボス) | 浮遊。弾幕・遅れて落ちる雷撃・手下の召喚・衝撃波 | 雷撃の予告円から離れる、手下を先に倒す |
| 影刃(ボス) | 素早い人型の剣士。三連斬・影走り(長い突進)・**背後取り**(予備動作の途中で消えて背後に現れる)。体力が半分を切ると**第二形態**(速さ1.3倍、攻撃の間隔0.6倍、アーマーが戻り、旋風刃と飛刃が増える) | 消えたら振り向いて回避、弱点の鎖・杖で攻める |

- エンドレスのボスは 鉄獣 → 魔導機 → 影刃 の順に出る

### プレイヤーのスキルを使う敵(実装済み)

敵もプレイヤーと同じスキルで攻めてくる。スキル(`SkillData`)を敵の攻撃に置き換えるのは `EnemySkillConverter`。

- **置き換え方**: 当たり判定・弾・落雷・突進・跳躍・瞬間移動(背後取り)などの形はスキルのまま。予備動作は 2.2倍+0.25秒(最短0.45秒)、威力は半分にして、見てから避けられる強さにする。多段の技は最大3回まで続けて出す
- **型の切り替え**: 武器種ごとの「型」(スキルの組)を持ち、7秒ごとなどに切り替える。**切り替えると弱点も変わる**ので、頭上の弱点を見てプレイヤーも持ち替える
- **見せ方**: 手に持つ武器が型の色になる。予備動作中は頭上に技の名前、切り替えた直後は「⇄ 大槌の型」を出す

| 敵 | 型1(弱点) | 型2(弱点) |
|---|---|---|
| 写し身・剣槌 | 剣: 連斬・居合・ステップ斬り(大槌・拳) | 大槌: 重撃・地砕き・ハンマージャンプ(剣・銃) |
| 写し身・杖銃 | 杖: 魔弾・落雷・ブリンク(剣・拳) | 銃: ラピッドショット・グレネード・スライド(鎖・杖) |
| 写し身・拳鎖 | 拳: 連打・昇龍拳・ロケットダッシュ(大槌・杖) | 鎖: 鎖鞭・縛鎖・ワイヤー(拳・銃) |

- **ボスにも混ぜる**(弱点はボスのまま)
  - 鉄獣: 地砕き・ハンマージャンプ
  - 魔導機: 落雷・魔弾
  - 影刃: 剣の型(居合・飛燕斬・残影)と鎖の型(縛鎖・鎖斬輪)を8秒ごとに切り替える
- **出てくる場所**: 新しいステージ「第5幕 写し身」(最後は影刃と写し身の同時戦)と、エンドレス(4〜6ウェーブ以降)
- 敵の攻撃に追加した仕組み: `teleportBehind`(背後取り)、`repeat`(同じ攻撃を続けて出す)、ボスの第二形態(`phase2HealthRatio` など)

## 6. メトロイドヴァニア要素

### 6.1 進入制限(スキルを鍵にする)

| 必要なスキル | 開く障害物 |
|---|---|
| 重撃(大槌A) | ひび割れた壁・床 |
| ハンマージャンプ(大槌・移動) | 高い段差 |
| ワイヤー(鎖・移動) | グラップルポイント |
| 引き寄せ(鎖B) | 遠くのレバーや足場を引き寄せる |
| ステップ斬り(剣・移動) | 閉まりかけの扉、細い隙間 |

- **鍵を移動スロットに集中させない**。攻撃A・攻撃B のスキルにも散らす
- 探索中にラックを組み替える必要が出すぎないよう、1つのエリアで必要な鍵は2〜3種類までに抑える

### 6.2 スキルの入手
- ボスの撃破(新しい武器種の解放)
- 探索中の宝箱や隠し部屋(既存の武器種の追加スキル)
- 将来: 刻片でスキルを強化する(派生技の追加、キャンセル窓の拡大 など)

### 6.3 探索モード「古城」(実装済み・試作)

ステージ選択の「探索  古城」で遊ぶ。アリーナとは別のマップで、**剣の3スキルだけ**を持って始め、マップに置かれたスキルを集めていく。

| 部屋 | 床の高さ | 置いてあるもの | 入るのに必要なもの |
|---|---|---|---|
| 入口の広間 | 0m | 祭壇(最初の再開地点) | — |
| 兵舎 | 0m | 重撃、雑兵×3 | — |
| 隠し部屋 | 0m | 旋風槌 | ひび割れた壁(大槌) |
| 崩れた大広間 | 0m | ハンマージャンプ、地砕き、重装兵+雑兵。中の高台(3m)に隕鉄投げ | ひび割れた壁(大槌) |
| 高台の庭 | 3m | ワイヤー、引き寄せ、鎖鞭、射手×2+疾風兵 | 高い段差(ハンマージャンプ) |
| 谷 | 床なし | ワイヤーのポイント3つ | ワイヤー |
| 塔の麓 | 3m | 祭壇、魔弾、ブリンク、飛蟲+疾風兵 | 谷を渡る |
| 闘技の間 | 3m | ボス「鉄獣」。倒すと 火球・落雷 を手に入れて探索クリア | — |

- 集められるスキルは 15(最初の3つを含む)。HUD の上に「集めたスキル n / 15」と、今いる部屋の名前を出す
- **スキルの入手**: 触れると手に入り、そのスロットが空いている最初のプリセットに自動で入る(すぐ使える)。編成画面では、まだ手に入れていないスキルは「？？？」で選べない
- **探索中の編成**: プリセット方式だけ。アリーナの編成とは別に保存する。空のプリセットには切り替わらない
- **進入制限**
  - ひび割れた壁: 大槌の技(近接の攻撃判定)で叩くと崩れる。ほかの武器では「大槌の技なら壊せそうだ」と出る
  - 高い段差: 3m。通常のジャンプ(約1.7m)では届かず、ハンマージャンプ(約3.7m)で乗れる
  - 谷: 床がない。ワイヤーでポイントを渡る(射程 18m、ポイントの間隔は 7〜10m)
- **祭壇**: 触れると体力が全回復し、倒れたときの再開地点になる(保存される)
- **落下**: 谷に落ちたら、最後に通った安全地点(谷の手前など)に戻り、15 ダメージ
- **敵**: 部屋に入ると現れ、全員倒すとその部屋は片付く(保存される)。ボス戦の間は入口がふさがる
- **保存**: 集めたスキル・壊した壁・取ったスキル・片付けた部屋・最後の祭壇。ステージ選択で探索を選んで **Backspace** で、はじめからにできる
- アリーナの各ステージは今までどおり、すべてのスキルを使える(練習用)
- カメラは壁の手前で止まる(探索の部屋や回廊で、壁の向こうに回り込まないように)

未決事項: 祭壇でだけ編成できるようにするか(今はどこでも P で開ける)、マップ画面、2つ目のエリア(銃・拳)

## 9. Unity での実装方針

### 9.1 データ駆動
- `SkillData`(ScriptableObject)
  - `slotType`(AttackA / AttackB / Movement)
  - `weaponType`(Sword / Hammer / Chain …)
  - 技のフェーズ(開始 / 攻撃判定 / 硬直)と各フレーム数
  - `cancelWindow`、`swapCancelWindow`
  - ダメージ、ひるみ値、アーマー破壊値、スタイルポイントの基本値
  - アニメーションクリップ、ヒットボックス定義、エフェクト、効果音
- `WeaponTypeData`: 武器種ごとのモデル(攻撃A・B・移動で共用)、マスタリー時のフィニッシャー、ボーナス値
- `StyleRankConfig`: ランクの閾値、減衰の速さ、各ボーナスの係数

→ プランナーがコードを触らずに、スキルの追加や数値調整をできるようにする。

### 9.2 主要なコンポーネント(案)
- `SkillSlotController`: 3スロット分のラックと現在の候補の管理、切り替え処理
- `SkillExecutor`: 技のフェーズ進行、キャンセル判定
- `WeaponHolder`: 手に持つ武器モデルの切り替え(攻撃B・移動の発動中の一時的な持ち替えと、終了後の復帰)
- `StyleRankSystem`: ポイントの計算、ランクの管理、UI への通知
- `LockOnSystem` + Cinemachine(**未導入のため追加が必要**)
- `InputBuffer`: Input System の上に先行入力バッファを実装する

### 9.2.1 IMGUI の注意(WebGL のクラッシュ対策)
- 文字サイズを画面の大きさや演出に合わせて変え続けると、動的フォントのテクスチャがあふれて再構築が無限に続き、
  WebGL で `memory access out of bounds` / `Maximum call stack size exceeded` になる
- HUD の文字は 1080p 基準の**決まったサイズ**で描き、`GUI.matrix` で画面全体を拡大縮小する。演出の拡大も `GUIUtility.ScaleAroundPivot` で行う

### 9.2.2 WebGL の軽量化
- ダウンロード量は Firebase Hosting の Brotli 圧縮後の値で見る(ファイルサイズの 1/3〜1/5 になる)
- 日本語フォントは使う文字だけに絞る: `python Tools/subset_font.py`(元のフォントは `Tools/Fonts`)。
  **スキル名や説明に新しい漢字を足したら実行し直す**(足りない文字は表示されない)。
  忘れると EditMode テスト `FontCoverageTests` が足りない文字を示して失敗する
- WebGL 専用の画質レベル「WebGL」と `WebGL_RPAsset` / `WebGL_Renderer` を `WebGLBuilder` が自動で作る
  (SSAO・ポストエフェクトなし、HDR なし、ハードシャドウ1カスケード、MSAA 2x)。PC / Mobile の画質は WebGL ビルドに含めない
- 高解像度ディスプレイは devicePixelRatio 1.5 倍まで
- 関数名(デバッグシンボル)は普段は入れない。クラッシュ調査のときだけ `BATTLEFIGHT_WEBGL_SYMBOLS=1` を付けてビルドする
- スプラッシュ画面は出さない
- コード: Managed Stripping High / IL2CPP OptimizeSize / Wasm DiskSizeLTO。自分たちのアセンブリ(`BattleFight.Runtime`)は
  `link.xml` で丸ごと残す。**リフレクションで使うコードを外部パッケージに足したら、WebGL で動くか必ず確認する**

### 9.2.3 Windows ビルド
- メニューの `BattleFight/Build Windows`(バッチ: `-buildTarget Win64 -executeMethod BattleFight.EditorTools.WindowsBuilder.BuildFromCommandLine`)
- 出力は `UnityProject/Builds/Windows/BattleFight.exe`、配布用に `UnityProject/Builds/BattleFight-Windows.zip` も作る
- スクリプトのバックエンドは Mono(IL2CPP より速く、Visual Studio の C++ ツールがいらない)。画質は通常の「PC」
- ウィンドウ化したフルスクリーンで起動する(Alt+Enter で切り替え)

- Git LFS の導入(モデル、テクスチャ、音声)
- Unity 向け .gitignore の確認
- シーンを直接編集する範囲を減らし、Prefab 単位で作業してマージ時の衝突を避ける

## 10. 用語集
